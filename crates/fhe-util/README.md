# fhe-util [![crate version](https://img.shields.io/crates/v/fhe-util.svg)](https://crates.io/crates/fhe-util) [![documentation](https://docs.rs/fhe-util/badge.svg)](https://docs.rs/fhe-util)

Utilities for [`fhe.rs`](https://github.com/gnosisguild/fhe.rs): primality
testing, centered-binomial sampling, modular arithmetic, and bit transcoding.

## Installation

Published crate:

```toml
[dependencies]
fhe-util = "0.4.1"
```

## Testing

```bash
cargo test -p fhe-util
```
